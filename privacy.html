森の小さな精霊 ― プライバシーポリシー

「森の小さな精霊」（以下「このゲーム」）の運営（個人で開発しています）は、遊んでくれる人の情報を、このページに書いたとおりに扱います。

1. 集める情報

あなたの端末の中だけに保存するもの

  • ゲームのセーブ（レベル・装備・どんぐりなど）と、ログボの記録

オンラインの機能（交流・ギルド・対戦など）を使うとき、サーバーに保存するもの

  • 匿名のログイン情報（ゲームが自動で作る番号です。メールアドレスや電話番号は使いません）
  • あなたが決めたプレイヤーの名前と、フレンドコード
  • ゲームの進み具合（レベル・強さ・装備・おとも・精霊術など）と、サーバーに置いたセーブ
  • 広場・ギルドでの発言
  • フレンド・おすそわけ・ギルド・対戦・お便りの記録
  • ブロック・通報の記録
  • ログイン用コード（引き継ぎコード。パスワードはそのままでは保存せず、元にもどせない形に変えて保存します）
  • ショップで買ったものの記録（商品・値段・日時・ストアの注文番号と購入トークン）と、買ったどんぐり（有償）を使った数
  • はじめて買うときに選んだ年齢の区分（16歳未満・16〜19歳・20歳以上。1か月に使える金額の上限のため）

遊び方の記録（オンラインの機能を使わなくても送ります）

  • 端末ごとのランダムな番号（ゲームが自動で作るものです。端末の ID や広告 ID は使いません）
  • 起動した日時・遊んだ時間・ステージとレベル・進化・おともを呼んだ回数・開いた画面・端末の種類（Android・ブラウザなど）・ゲームの版

オンラインの機能を始めた人は、この記録をプレイヤーと結びます。

通信のときに自動で記録されるもの

  • サーバーや配信元が通信のときに残す接続の記録（IPアドレス・日時・端末やブラウザの種類など）

次のものは集めません: 本名、メールアドレス、電話番号、住所、位置情報、連絡先、写真、広告ID。
ショップの支払い（カード番号など）は Google Play・Steam などのストアが扱い、運営は受け取りません。運営は、支払いが本物かを確かめるため、Google Play に購入トークンを問い合わせます。
このゲームには広告と、外部の会社の分析ツールは入っていません（遊び方の記録は、運営のサーバーにだけ送ります）。

2. 使い道

  • オンラインの機能（交流・フレンド・ギルド・対戦・ランキング・お便り）を動かすため
  • セーブを守り、別の端末に引き継ぐため
  • ショップで買ったものを届けるため
  • 未成年の方の1か月の購入金額に上限を設けるため、法令にもとづく記録（資金決済法）を残すため
  • ずるや迷惑な行為を防ぎ、通報に対応するため
  • 不具合を直し、サービスを安全に動かすため
  • どこでむずかしく感じているか・続けて遊ばれているかを見て、ゲームをよくするため（遊び方の記録）

3. ほかのプレイヤーに見えるもの

プレイヤーの名前、強さ、プロフィール（レベル・精霊の姿・おともなど）、対戦の成績、ギルド、広場・ギルドでの発言は、ほかのプレイヤーにも見えます。名前や発言に、本名や連絡先などを書かないでください。

4. 外部のサービス

このゲームは、次のサービスを使って動いています。情報はこれらのサービスのサーバー（日本の外にあることがあります）に保存されます。

  • Supabase（オンラインの機能のサーバー）
  • GitHub Pages（ブラウザ版の配信）
  • Google Play・Steam（ゲームの配信と、ショップの支払い）

法令にもとづく場合をのぞき、集めた情報を、あなたの同意なしにほかの人や会社に渡したり売ったりしません。

5. 保存する期間と、消し方

サーバーの情報は、あなたが消すまで保存します。遊び方の記録は、1年たつと消します。ゲームの中からいつでも消せます。消し方と、消したあとも残るもの（通報の記録・売上の記録など）は、データの削除のページに書いています。

6. 子どもの利用

このゲームにはプレイヤー同士で話せる機能があります。13歳未満の方は、保護者の方の同意を得てから遊んでください。ショップで買うときも、保護者の方と相談してください。

7. 安全のための取り組み

通信は暗号化（HTTPS）しています。サーバーの情報は、本人と運営しか読み書きできないようにしています。

8. このページの変更

内容を変えるときは、このページでお知らせします。
